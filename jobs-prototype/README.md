# Jobs prototype

Open index.html from a checkout of the prototype repository, or open the jobs-prototype directory on GitHub Pages. No build step is required.

Use the Jobs List to search by Job reference, customer, site or service and filter by scheduled date, status and Trip. Open a Job by selecting its reference. Choose Edit Job to update details, then Save changes or Cancel.

The screens reuse the Day Board’s sample data and status labels. Sample Jobs cover three dates. Edits persist in the current browser under a separate storage key. The Day Board and Add Job prototypes operate independently. Lifecycle statuses are shown in Job Details and continue to be managed through the operational workflow represented by the Day Board.
